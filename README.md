## 📋 Descripción

Proyecto backend que muestra competencias en APIs, arquitectura limpia y patrones. Migrado, historial reescrito, documentado para portfolio.

## 🏗️ Arquitectura

Clean Architecture / Layered Architecture

## 🚀 Inicio Rápido

### Prerrequisitos

.NET 8 SDK, Node.js 20+ (para mc-nuts-api-design)

### Instalación

```bash
# Clonar
git clone https://github.com/J1u2a3n8/mc-nuts-creative-patterns.git
cd mc-nuts-creative-patterns

dotnet restore
# dotnet build
```

### Uso

```bash
dotnet run --project src/
```

## 🧪 Tests

```bash
dotnet test
```
