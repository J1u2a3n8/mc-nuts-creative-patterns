## Description

Implementation of all 5 GoF Creational Design Patterns (Factory Method, Abstract Factory, Builder, Prototype, Singleton) with practical examples showing when and how to apply each pattern in C#.

## Architecture

Pattern-based modular structure with isolated examples per pattern

## Quick Start

### Prerequisites

.NET 8 SDK, Node.js 20+ (for mc-nuts-api-design)

### Installation

```bash
# Clone
git clone https://github.com/J1u2a3n8/mc-nuts-creative-patterns.git
cd mc-nuts-creative-patterns

dotnet restore
# dotnet build
```

### Usage

```bash
dotnet run --project src/
```

## Testing

```bash
dotnet test
```
